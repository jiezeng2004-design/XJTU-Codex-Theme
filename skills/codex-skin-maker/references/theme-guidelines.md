# 皮肤设计与可读性规范

## 图片选择

优先条件：

- JPEG、PNG 或 WebP；
- 16:9，推荐 2560×1440；
- 主体位于画面右侧或中右侧；
- 左侧低信息、低对比，方便侧栏文字显示；
- 不包含账号、令牌、私密对话、地址、证件等敏感信息。

图片不满足推荐比例时，可以创建非破坏性派生图，但不得覆盖原图。裁剪应优先保留主体，避免把重要人物面部、校徽或文字压在侧栏和输入区后方。

## 主题 ID 和目录

- ID 只使用小写字母、数字和连字符；
- 最长 64 个字符；
- 深色和浅色共用基础 ID，通过 manifest 的 `variant` 区分；
- 不覆盖 `xjtu-academic-dark`、`xjtu-academic-light` 或无品牌模板；
- 资源应保存在项目内部，例如：

```text
themes/campus-sunset/
├─ assets/
│  ├─ dark.webp
│  └─ light.webp
├─ dark.json
└─ light.json
```

如果项目现有结构要求只维护 active manifest，可以保留派生 manifest 作为主题源，同时更新：

- `engine/themes/dark.json`
- `engine/themes/light.json`

## 深色模式

推荐起点：

- `background`: 接近深蓝黑或深灰；
- `panel`: 比背景略亮，确保输入框和侧栏可辨识；
- `text`: 接近白色但避免纯白刺眼；
- `muted`: 保持与面板至少有明显层级；
- `accent`: 从图片中提取一个高辨识度颜色；
- `bodyScrimStart/End`: 通常 30%–50%；
- `sidebarScrimStart/End`: 通常 70%–90%。

深色模式不能只把浅色值整体反相。必须单独检查按钮、输入框、代码块、焦点态和选中态。

## 浅色模式

推荐起点：

- `background`: 柔和浅灰、米白或低饱和主题色；
- `panel`: 接近白色但与背景保持边界；
- `text`: 深灰或近黑；
- `muted`: 不得淡到难以阅读；
- `line`: 使用低透明度深色；
- 图片过亮时增加局部遮罩，而不是无限降低文字对比度。

## 布局参数

- `positionX`: 主体位于右侧时通常为 `64%`–`76%`；
- `zoom`: 通常为 `105%`–`118%`；
- 所有百分比参数不应超过 `120%`；
- `conversationWallpaper`: 默认 `false`；
- 只有用户明确希望长对话正文显示壁纸，并且文字可读性通过时，才设为 `true`。

## 最低可读性检查

至少人工或通过截图确认：

1. 左侧会话列表标题可读；
2. 新建会话和设置入口可辨认；
3. 主标题、正文和次要文字层级清楚；
4. 输入框边界和占位文字可见；
5. 发送按钮、附件按钮、焦点态不消失；
6. 代码块与普通正文能区分；
7. 图片主体未遮挡主要操作区；
8. 指针事件未被背景层拦截。

## 素材权利边界

- 优先使用用户本人拍摄、本人生成或明确授权的图片；
- 不主动从网络搜索并下载来源不明的校徽、动漫角色、摄影作品或品牌素材；
- 不移除第三方水印；
- 用户自己的浅水印可以保留；
- “非官方个人主题”声明不等于获得商标、学校标识或角色版权授权。
