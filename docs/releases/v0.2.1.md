# XJTU Codex Theme v0.2.1

First public source-available release of XJTU Codex Theme.

## Highlights

- Ready-to-use XJTU Academic Dark and Light themes.
- Apply and switch themes without restarting Codex Desktop.
- PID-verified loopback Inspector pulse with immediate port cleanup.
- Renderer health verification and guarded `disable` recovery.
- One-click Windows desktop shortcuts.
- Unbranded light/dark template for custom image-based themes.
- Optional `codex-theme-author` Skill and step-by-step Codex authoring guide.

## Demo

The attached `xjtu-codex-theme-demo.mp4` is a silent 12-second demonstration of switching from the light theme to the dark theme without restarting Codex.

## Verified environment

- Windows 10/11 x64
- Microsoft Store Codex `26.715.7063.0`
- Node.js 22 or newer

## Safety notes

Run `xjtu-theme.cmd doctor` before the first preview. Use `xjtu-theme.cmd verify` after applying a theme and `xjtu-theme.cmd disable` to remove it. Other Codex versions are unverified and may require adapter changes.
